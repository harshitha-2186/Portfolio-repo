# Personal Portfolio Page

A responsive one-page portfolio website built with HTML, CSS and a little JavaScript.

## Features
- Sticky gradient navigation bar with smooth scrolling
- Sections: Hero, About, Skills, Projects, Contact
- Project cards with hover effects
- Fully responsive layout with a mobile hamburger menu

## Built With
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (mobile menu toggle)

## Run Locally
1. Clone the repository
   ```
   git clone https://github.com/YOUR-USERNAME/portfolio.git
   ```
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**
